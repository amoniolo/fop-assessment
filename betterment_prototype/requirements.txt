# --- Version notes ---
#
# QuantStats must be 0.0.65 or later. Release 0.0.64 declares numpy<2.0.0 in
# its metadata, and numpy below 2.1 has no wheel for Python 3.13, so that
# combination is unresolvable on this interpreter -- pip fails with
# ResolutionImpossible before anything is installed. The pin is a conservative
# metadata declaration rather than a real code incompatibility (0.0.64 runs
# correctly under numpy 2 when the pin is bypassed), but a dependency resolver
# acts on declared metadata, so the effect is the same.
#
# PyPortfolioOpt must be 1.6.0 or later for the same reason: 1.5.6 pins an
# older numpy range that cannot be satisfied here.
#
# yfinance 1.7.0 is a major version ahead of the 0.2.x series. utils/data.py
# normalises whichever column shape yfinance returns, so both work; 1.7.0 is
# pinned because it is what was tested.
