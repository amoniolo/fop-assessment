# ===========================================================================
# SIDE NOTE - on using a newer pandas
# ===========================================================================
#
# The four supporting versions above are deliberately NOT the newest releases.
# They are the set the project was actually verified on, and they match the
# stack that ships with a current Anaconda distribution (Python 3.13.9).
#
# The code itself is not restricted to them. An earlier pinned set - pandas
# 3.0.5, numpy 2.5.2, scipy 1.18.1, matplotlib 3.11.1 - also passed all 46
# engine tests and produced figures identical to the set above, so nothing in
# this project depends on pandas 2.x behaviour. None of the four finance
# libraries forces the choice either; all accept a wide range:
#
#     QuantStats 0.0.81      pandas>=1.5.0
#     PyPortfolioOpt 1.6.0   pandas>=1.0.0,<4.0.0
#     yfinance 1.7.0         pandas>=1.3.0
#     numpy-financial 1.0.0  (no pandas constraint)
#
# The reason for stepping back from pandas 3.0.5 is environmental rather than
# technical. On a managed Windows machine, importing the pandas 3.0.5 *pip
# wheel* was refused outright by Windows Application Control:
#
#     ImportError: DLL load failed while importing period:
#     An Application Control policy has blocked this file.
#
# pandas 3.0 is a very new major release, so its binaries have little
# reputation data behind them and security policies on locked-down machines
# block them. The conda-channel build of pandas 2.3.3 loaded without any
# such problem on the same machine. Since this package has to run on a
# marker's computer rather than only on the author's, the version that
# installs everywhere is worth more than the version that is newest.
#
# To run on the latest stack instead, replace the four supporting pins with:
#
#     pandas>=2.2
#     numpy>=2.1
#     scipy>=1.14
#     matplotlib>=3.9
#
# That is expected to work and was tested on pandas 3.0.5 specifically, but
# the exact versions pip resolves will drift over time, so the figures in the
# report are only guaranteed to reproduce with the pins at the top of this
# file.
